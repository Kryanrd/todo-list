# To-Do List

## О проекте

To-Do List - небольшое веб-приложение для создания и управления списком повседневных задач. Пользователь может добавлять новые задачи, отмечать выполненные, удалять отдельные записи и очищать весь список.

Проект разработан с использованием HTML, CSS и JavaScript без сторонних библиотек и фреймворков. Для сохранения задач между посещениями страницы используется Local Storage браузера.

## Функциональность

- **Добавление задач:** создание новых задач с проверкой заполнения поля ввода.
- **Отметка выполнения:** изменение статуса задачи с помощью чекбокса.
- **Удаление задач:** возможность удалять отдельные записи из списка.
- **Очистка списка:** удаление всех задач с предварительным подтверждением действия.
- **Сохранение данных:** автоматическое сохранение списка задач в Local Storage.
- **Восстановление данных:** загрузка ранее сохранённых задач при повторном открытии приложения.
- **Динамическое обновление интерфейса:** автоматическое отображение изменений списка после добавления или удаления задач.

## Особенности реализации

- Использование JavaScript (ES6+) для обработки пользовательских действий.
- Работа с DOM API для динамического создания, изменения и удаления HTML-элементов.
- Обработка событий `submit`, `click` и `change`.
- Использование массивов и объектов для хранения и обработки списка задач.
- Преобразование данных с помощью `JSON.stringify()` и `JSON.parse()`.
- Работа с Web Storage API для сохранения данных в браузере.
- Использование CSS для оформления интерфейса и визуального отображения статуса выполненных задач.

## Технологии

- **HTML5** - структура приложения.
- **CSS3** - стилизация пользовательского интерфейса.
- **JavaScript (ES6+)** - логика приложения и обработка пользовательских событий.
- **DOM API** - динамическое взаимодействие с HTML-элементами.
- **Web Storage API (Local Storage)** - сохранение списка задач в браузере.

## Запуск проекта

Для запуска приложения не требуется установка дополнительных зависимостей или инструментов сборки.

### 1. Клонирование репозитория

```bash
git clone https://github.com/Kryanrd/todo-list.git
cd todo-list
```

### 2. Запуск приложения

Откройте файл `index.html` в браузере.

Также можно использовать расширение **Live Server** в Visual Studio Code для запуска проекта через локальный веб-сервер.

После открытия страницы приложение готово к работе.
